# 옵션 설명
야외 방송 시 Person과 Face를 블러 처리하여, 행인의 초상권을 보호하는 것을 목표로 추천값을 설명합니다.

> [!IMPORTANT]
> 이 필터는 더 안정적으로 트래킹하기 위해, 기본적으로 지연 시간 **0.5초**를 추가합니다.

> [!TIP]
> 필터 하단에 ```기본값```을 누르면, 모든 항목이 Person 추천 값으로 돌아갑니다.

### 기본 설정
- **모델**
  - 추천 값: Person ```중간``` 또는 ```큼```, Face ```YOLOv8n-Face (얼굴 검출, 정확함)``` 이상
- **객체 카테고리**
  - 추천 값: ```Person```, ```Face```
- **신뢰도 임계값**
  - 이 값보다 높은 신뢰도를 가진 객체만 인식합니다.
  - 추천 값: Person ```0.45```, Face ```0.35```
- **최소 객체 면적**
  - 이 값보다 작은 객체는 인식하지 않습니다.
  - 추천 값: Person ```3000```, Face ```50```
### 마스킹
- **마스킹 유형**
  - 추천 값: ```블러``` 또는 ```모자이크```
- **강도**
  - 추천 값: ```10```
- **경계선 페더**
  - 추천 값: ```30```
- **마스크 동적 확장**
  - 마스킹 영역을 인식된 객체 크기에 비례하여 확장합니다.
  - 추천 값: ```활성화```
    - **동적 확장 기본 크기 (픽셀)**
      - 객체의 기본 확장 크기입니다.
      - 추천 값: Person ```1.00```, Face ```2.00```
    - **동적 확장 배율**
      - 객체가 더 커질수록 마스킹이 배율에 비례하여 더 커집니다.
        - 예: 얼굴이 멀리있을땐 크기가 작아서 얼굴 전체가 가려지지만, 가깝다면 머리카락과 귀가 노출될 수 있으므로, 더 크게 마스킹합니다.
      - 추천 값: Person ```0.05```, Face ```0.25```
### 특정 대상 마스킹 제외 (얼굴 인식)
> 자세한 가이드는 [여기](FACE_GUIDE_KR.md)를 참고하세요.
- **사람 카테고리**
  - 만약 여러 객체를 추적할 경우, 어떤 것이 사람 객체인지 지정합니다.
  - 사람, 얼굴로 객체를 이미 지정했다면, 굳이 설정할 필요는 없습니다.
- **제외 대상 얼굴 사진**
  - 얼굴 사진 폴더를 선택합니다.
- **얼굴 일치 유사도 임계값**
  - 이 값보다 높은 유사도를 가진 얼굴을 마스킹에서 제외합니다.
  - 추천 값: ```0.60```
- **객체 인식 최소 크기**
  - 얼굴 인식을 진행하기 위해 필요한 객체의 최소 크기입니다.
    - **얼굴이 아닌 객체 카테고리에 설정된 객체의 크기입니다!**
  - 멀리 있는 사람을 오인식 하지 않기 위해 필요한 옵션입니다.
  - 추천 값: Person ```19.00```, Face ```0.60```
- **얼굴 인식 체크 주기 (프레임)**
  - 프레임 간격마다 얼굴을 인식합니다.
  - 성능이 여유롭다면 짧게 설정하여도 좋습니다만, 다른 사람의 얼굴 유사도가 순간 치솟아 임계값을 넘길 가능성도 있으니 주의하세요.
  - 추천 값: ```5```~```15``` (30fps 기준)
- **최대 제외 객체 수 제한**
  - 제외하고 싶은 사람이 총 몇 명인지 정합니다.
  - 0은 무제한입니다.
### 연속 트래킹
- **최소 인식 유지 프레임**
  - 객체를 인식했을때, 연속으로 몇 프레임동안 유지해야 마스킹을 시작할지 설정합니다.
    - 이 프레임보다 적은 프레임동안 객체가 인식되었다면 마스킹하지 않습니다. (잠깐의 놓침은 무시됩니다.)
  - 추천 값: ```5```
- **최소 인식 프레임 무시 크기 임계값**
  - 이 값보다 큰 객체는 `최소 인식 유지 프레임`을 무시하고 즉시 마스킹을 시작합니다.
    - 즉, 사람이 카메라 앞에서 `최소 인식 유지 프레임`보다 빠르게 등장했다 사라져도 놓치지 않고 마스킹합니다.
  - 추천 값: Person ```4.00```, Face ```0.80```
- **최대 미인식 허용 프레임**
  - 객체 추적을 놓친 경우, 이 프레임 동안 마스킹을 유지하고, 이 프레임을 넘겨도 다시 찾지 못하면 마스킹을 해제합니다.
  - 추천 값: ```15```
- **IoU 임계값 (중첩 허용치)**
  - 이전 프레임과 현재 프레임에서 인식된 객체의 겹침 정도를 나타내는 값으로, 이 값보다 더 낮은 IoU를 가진 객체는 별도의 객체로 인식합니다.
  - 추천 값: Person ```0.19```, Face ```0.01```
- **놓친 객체 복구 거리 배율**
  - 객체가 겹치지 않아 객체 추적을 완전히 놓친 경우, 객체 크기의 배율에 비례하여 마스킹 영역을 확장하고, 해당 영역내에서 객체를 탐색합니다.
    - 사람이나 얼굴이 너무 빠르게 이동하는 경우에도, 같은 객체로 인식하기 위함입니다.
  - 추천 값: Person ```1.80```, Face ```2.50```
- **놓친 객체 복구 크기 차이 배율 제한**
  - 복구 거리 배율 내에서 찾은 객체의 크기가, 놓친 객체 크기보다 이 배율 차이가 적은 경우에만 같은 객체로 판단합니다.
  - 추천 값: ```1.70```
